Valódi online szinkron (GitHub Pages) – Supabase beállítás

GitHub Pages statikus, ezért a valós idejű multiplayerhez kell egy realtime szolgáltatás. A kód támogatja a Supabase Realtime Broadcastot (ingyenes csomag is elég).

  1. Hozz létre Supabase projektet.
  2. Project Settings → API: másold ki az Project URL és anon key-t.
  3. Room oldalon → Realtime panel → illeszd be (localStorage-be menti).

Ha nincs Supabase, akkor is megy single-player, és van manuális “state copy/paste” szinkron.
